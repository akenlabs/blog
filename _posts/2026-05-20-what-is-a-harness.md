很多朋友都会问我，国内到底能不能用 Claude Code？

长话短说，答案是能。

大家都听说 Claude Code 很好用，但也会担心 Anthropic 对中国地区限制比较多，账号容易出问题，所以特别关心自己到底能不能用上。

这里要先区分两件事。

Claude 是模型。

Claude Code 是 Agent 工具。

模型提供能力，工具框架负责把能力接到真实任务里。

这也和最近一年 AI 领域很重要的一个概念harness 有关。

harness 原意是马具，用来驾驭马匹，在 AI 领域指的是驾驭 AI 的系统。

类比来看，现在的大模型就像一匹马，能力很强，冲劲很大。

但如果没有一套好的驾驭系统和工具，我们其实很难真正用好它。

harness 的价值就在于给模型补上记忆、工具、反馈和编排能力。

让它不只是“会回答”，而是真的能进入工作现场，把任务往前推进。

Claude Code 本身就可以理解成一套成熟的 harness。

它不只是让模型像聊天机器人一样输入文字、输出文字，而是让模型进入我们的工作现场：

了解项目、读文件、改代码、跑命令、根据反馈继续调整。

通过这套马具，Agent 才能产生更多真实落地的工作价值。

回到最初的问题，Claude Code 作为一套商用级、持续迭代的 harness，能力是顶尖的。原生搭配 Claude 模型，通常效果最好。

但这不代表底层模型不能换。

就像我们有了一套马具，不一定只能配原来那匹马，也可以放到其他马匹身上。

比如国内的 Kimi、DeepSeek，其实都有一些对 Claude Code 的适配。

我自己甚至会把竞争对手的 GPT 系列模型接进去，一样可以工作。

所以国内朋友不用太担心，Claude Code 是可以下载、用上的，只是底层模型要根据自己的条件做调整。

有条件、愿意折腾，可以配原生 Claude。

不想折腾，也可以先配国内模型。

最后分享一个感悟，模型的能力，只是潜力，有了 harness，才会变成真正的生产力。
