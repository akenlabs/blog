你的手机里是不是也有一个灵感记录 app、一个待办事项 app、一个日程管理 app？

过去我也是。

直到我用一个 Hermes Agent 替代了它们全部。

刘润老师在视频里也分享过类似的用法。因为每天要输出一份日报，他平时零零散散会有一些灵感和想法，他就交给 Agent 去收集。等真正动笔写的时候，直接从想法库里提取梳理，不用临时构思。

这在以前是笔记/灵感管理 app 的工作，现在 agent 可以替代了。

但其实没有停止，这个 agent 可以处理更多的工作。

我自己专门建了个人助理 agent ，让它记录想法到数据库，同时它还能创建待办事项、查看我的日程日历、定时巡检提醒我还有哪些任务等着去完成。

过去这些工作真的需要分很多个 app 来完成，在不同 app 之间来回切换。

但现在一个 Agent 就实现了。

所以为什么博主第四种黑猩猩说未来 80% 的 app 都会消失，不是它们不好用了，而是 Agent 现在可以自定义它的技能和能力，替代了原来我们用 app 的那部分时间和操作。

如果你还没开始去捏自己的 Agent，可以尽快开始试一试，它可以替代你原来在多个 app 之间切换的时间还有注意力的消耗。而在这个过程中，我们开始在 Agent 里面积累自己的数据，越用越懂你，越懂你，未来也会越好用。
