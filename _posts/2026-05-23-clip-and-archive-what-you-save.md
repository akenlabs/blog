你想不想在存资料的时候，前端能接收一切格式，而且能帮你做一部分的预处理？

刘润老师在他的分享里面就提到过这个用法。

他把一篇西班牙文的文章丢给 Agent，在剪存的同时让 Agent 同步翻译。等到后面再去调用的时候，存下来的已经是一个中西双语的版本了，省掉了预处理的时间。

以前不同格式的资料需要不同的工具。

网页用收藏夹，文档放网盘，视频存本地，音频也存本地。每换一种格式，就要换一个地方。

但现在这些都能通过 Agent 去处理了。

因为底层上 Agent 有非常丰富的可以自定义 skill 的空间，每一种格式只要匹配上对应的工具，都能够进行处理，所以前端能够收集非常多种类的资料。

收集只是第一步，后续预处理或者深度加工，也可以通过 skill 来实现。

我自己也是这样。我现在搭建了一个专门存资料的 skill。

刷 X 或者网页上读到不错的文章，觉得有深入阅读的空间，但当下没法展开，就把链接甩给 Agent。它根据我之前定义的 skill，把完整内容抓取下来，存到 Notion 里面。

这样也不怕图片或者链接因为时间太长而失效，也不怕原来的内容被改动或者被博主删除。

前端能接受一切格式，后端能做一切加工，这就是 Agent 跟传统"存资料"最大的区别。
