在一线做业务的老板都知道，客户说过的话，其实比很多市场报告更值钱。

但问题是，这些话最后往往没有留下来。

这两年我们在惠州做家纺家居门店时，就给销售搭过一个 Agent。最早用扣子，接到豆包，后来又换成 OpenClaw 和 Hermes Agent。

当时我们特别想积累客户信息：客户看过什么产品、从哪里来、什么年龄段、真实需求是什么、犹豫点在哪里。

但一线销售很忙，能力水平也有差距。让他们每天再去写一份结构化客户记录，成本太高。

所以后来我们换了一个做法：

第一步，先选一个合适的工具。

对一线销售来说，最好不用让他打开一个复杂系统打字，而是能直接发语音。

如果把 OpenClaw 或 Hermes Agent 接到飞书里用，可能还要单独配置语音转录模型；但如果接入到微信clawbot，就可以直接用微信自带的语音转文字能力。

销售只要在微信里说一段客户沟通情况，后面再交给 Agent 做结构化整理，使用门槛会低很多。

第二步，给 Agent 设定一个结构化信息提取模板。

提前告诉它我们在意哪些字段，比如年龄段、客户来源、产品需求、关注点、犹豫点、后续跟进建议等等。

这样销售不用每次重新想“我要记录什么”，只要把客户现场说出来。

第三步，先跑通一遍。

让销售用语音随便说一段客户沟通情况，想到哪说到哪，再看 Agent 按模板整理出来的信息是否符合预期。

如果有遗漏，就继续补字段；如果回复太多或太少，也可以继续调。

等这个流程稳定下来，再把它固化成一个 Skill，或者固定工作流。

最后做一个简单培训，告诉一线同事怎么用。

这样销售不用变成“会写总结的人”，只要把客户现场说出来。结构化整理这件事，交给 Agent。

短期看，周会、月会、季度会时，我们能更清楚地看到哪些客户还能跟进，哪些客户还有成交机会。

长期看，这些信息积累下来，就是最宝贵的客户洞察。可以做关键词分析，也可以看到客户真实心声，再反过来调整产品和销售策略。

客户关系系统里的信息，不只是一个表格、一个页面。

它是离生意最近的市场信号，也是客户愿意给我们的，最真实的反馈。
